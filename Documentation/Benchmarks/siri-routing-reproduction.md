## Published implementation

Zforge's modern `OpenZforgeContentIntent` adopts `system.open`, supports foreground execution and takes a `ZforgeArchiveEntity` target. Entities conform to `IndexedEntity` and are explicitly donated to the named `ZforgeAuthorizedArchives` index. Query and perform diagnostics distinguish routing from contextual folder permission. The original four archive actions and the separately available legacy Spotlight OpenIntent remain. No compatible public compression/extraction schema is assigned.

The index publishes only verified visible regular archives directly inside authorized automation roots. It retains canonical physical identifiers and maps directory-alias presentation paths for onscreen associations. Live authorization is rechecked before every opening; Spotlight is not a file-access grant.
