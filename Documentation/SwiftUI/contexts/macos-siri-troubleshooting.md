# If Siri on Mac doesn’t work as expected

## Summary

**Official summary:** Apple recommends checking the internet connection, whether Siri is enabled, and microphone availability. For an external microphone, verify the selected input and sufficient volume. Screen Time restrictions can prevent enabling Siri.

For Zforge diagnostics, first establish supported basic commands and inspect configuration without modifying privacy settings. A successful typed request does not establish spoken recognition or third-party action routing.
