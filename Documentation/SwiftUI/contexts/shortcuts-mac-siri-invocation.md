# Run saved shortcuts with Siri on Mac

## Summary

Apple's Mac guide instructs people to activate Siri and say a saved shortcut's name. Siri reports the result after execution. An app-opening shortcut on a locked device requires unlocking.

## Zforge implications and observed limit

This supports the custom shortcut setup for native Mac App Intents. It does not prove local discovery: three actual Siri queries on macOS 27.0.1 fail to find Compactar com Zforge after the name is visibly saved in the library. Do not infer success from this generic guide, editor discovery or direct intent execution.
