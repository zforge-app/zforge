# NSOpenPanel

## Summary

NSOpenPanel supplies native file or directory selection and explicit user consent. Zforge restricts selection to the exact requested directory, validates the physical scope, and saves its security-scoped bookmark only after confirmation.

## Availability and validation

macOS


Validated against the macOS 27 SDK; Zforge deploys to macOS 26. API compilation does not establish successful native foreground or panel presentation.
