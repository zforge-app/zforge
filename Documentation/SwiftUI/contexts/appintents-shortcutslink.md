# ShortcutsLink

## Summary

ShortcutsLink provides a SwiftUI control to open the Shortcuts app. The captured declaration lists iOS, iPadOS, Mac Catalyst and visionOS, without native macOS. The local Xcode 27 native macOS SDK has no ShortcutsLink declaration.

## Practical implications

Use the existing native AppKit application lookup/opening APIs for the Mac button, and localize its label and unavailable-app feedback.
