# QLThumbnailGenerator

## Quick reference

- Module: Quick Look Thumbnailing
- Availability recorded by the source: iOS 13.0, iPadOS 13.0, Mac Catalyst 13.1, macOS 10.15, visionOS 1.0.
- Zforge SDK verification: Xcode 27.0, macOS SDK 27.0, arm64; application target macOS 26.0.
- Declaration: `class QLThumbnailGenerator`

## Summary and practical implications

Generate content representations asynchronously and cancel requests that no longer belong to a visible cell. The request controls the requested size and allowed representations; rendering still depends on an available provider.
